Política de privacidad de la skill de Alexa «Almacén»

Última actualización: 13 de octubre de 2026

«Almacén» («Alexa, abre guardar en almacén») es una skill gratuita que permite llevar por voz el inventario de un almacén, una despensa o un pequeño negocio. Esta página explica qué datos usa y para qué.

Qué datos guarda

  • Los productos y cantidades que le dictas (por ejemplo, «3 kilos de arroz»), el límite de «poco stock» si lo cambias y el número de veces que has abierto la skill.
  • Estos datos se asocian a un identificador anónimo que Amazon asigna a tu cuenta para esta skill. La skill no conoce tu nombre de cuenta, tu correo ni tu dirección.

Tu nombre

Si das permiso en la app de Alexa, la skill lee tu nombre de pila solo para saludarte al abrirla. El nombre no se guarda ni se comparte. El permiso es opcional y puedes retirarlo cuando quieras en la app de Alexa.

Dónde se guardan

En un almacenamiento privado de la skill en Amazon Web Services (Alexa-hosted skills, región de Estados Unidos), al que solo tiene acceso el desarrollador de la skill. Los registros técnicos de funcionamiento solo anotan el tipo de petición (por ejemplo, «guardar producto»), nunca el contenido de tu almacén ni identificadores de usuario.

Con quién se comparten

Con nadie. No se venden, no se usan para publicidad y no se ceden a terceros.

Cómo borrarlos

  • Di «Alexa, pide a guardar en almacén que vacíe el almacén» para borrar todos tus productos.
  • Para que se borren también el resto de datos asociados, escribe por el canal de contacto de abajo.

Menores

La skill no está dirigida a menores de 13 años.

Cambios

Si esta política cambia, se actualizará esta página y su fecha.

Contacto

Para cualquier duda, sugerencia o petición sobre tus datos, abre una incidencia en github.com/claudiusava/skill-alexa-el-almacen/issues.
